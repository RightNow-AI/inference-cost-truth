## PAGES I COULD NOT FETCH

- `https://b0.p.awsstatic.com/pricing/2.0/meteredUnitMaps` returned HTTP 403 when fetched as a bare directory-like endpoint. The concrete official Bedrock JSON endpoints discovered in the AWS bundle were fetched successfully with HTTP 200 and saved, including both compressed raw bodies and decoded JSON.

## THINGS I COULD NOT VERIFY

- DeepSeek does not publish a currently effective off-peak discount. Its page describes a future peak-price policy, gives a Beijing-time window, and says the effective date will be announced later. I did not report a computed UTC conversion because those converted clock values do not occur literally in the vendor response, which would violate the evidence law.
- xAI publishes model-level batch discounts and a priority multiplier, but not literal final batch/priority per-token amounts for every model. I did not derive those prices.
- Several Amazon Bedrock model families are rendered as price-key placeholders and resolved through a separate metered-unit JSON response. Where a per-million result required arithmetic, I omitted the row rather than create a number that was absent from a single raw evidence body. This especially affects parts of the Amazon Nova, AI21, Anthropic, Cohere, Meta, and other dynamically rendered catalogs.
- Cohere publishes no production per-token price for Command A+, Command A Reasoning, Command A Translate, or Command A Vision on their model pages. Those models are retained with null token fields and the official access condition in notes.
- Azure legacy rows quoted per thousand tokens were not converted because the required per-million result is not literal in the raw page. Azure rows without a usable East US global-deployment value were also omitted.
- Vertex legacy Gemini rows priced by characters are retained with null token fields and a loud warning; character prices were not silently converted to token prices.
- Context windows remain null whenever the pricing evidence itself did not publish a context size. No context size was imported from memory or a third-party source.
- The cloud-host pages mix model availability, region, deployment mode, and future-dated promotional rows. The row notes state the selected host/owner/region interpretation; promotional labels are preserved verbatim in model names when present.
